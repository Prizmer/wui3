Отчёт №114: Показания на дату. 3 тарифа

Назначение отчёта: формирование таблицы показаний по электроэнергии на выбранную дату с учётом трёх тарифов (T1, T2, T3) и автоматическим пересчётом в энергию с применением коэффициентов трансформации (КТТ, КТН).

Порядок работы:

  1. В панели ресурсов (слева) выберите «Электроэнергия»
  2. В дереве объектов раскройте нужный объект (ЖК, корпус).
  3. В выпадающем списке отчётов выберите «№114 — Показания на дату. 3 тарифа».
  4. В появившемся календаре справа укажите дату, за которую необходимы данные.
  5. Дождитесь формирования таблицы в центральной области экрана.
  6. Для выгрузки данных в файл Excel нажмите кнопку «Экспорт», расположенную рядом с выпадающим списком отчётов.
Примечание: В данном отчёте выполняется пересчёт показаний приборов учёта в энергию с учётом коэффициентов трансформации (КТТ, КТН). Для квартирных приборов учёта указанные коэффициенты, как правило, равны единице.
Важно: Если на выбранную дату в базе данных отсутствуют показания по одному или нескольким приборам учёта, в соответствующих ячейках таблицы будет отображено значение Н/Д (или иное значение, предусмотренное индивидуальными настройками отчёта).

Сформированный файл отчёта будет сохранён в папку «Загрузки» (или иную директорию, заданную в настройках вашего браузера).
