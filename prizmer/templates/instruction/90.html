Отчёт №90: Статистика опросов. Вода импульсная

Назначение отчёта: получение сводной статистики по опросу всех импульсных водосчётчиков за выбранную дату. Отчёт позволяет оценить качество сбора данных и выявить приборы, которые не были опрошены.

Примечание: Данный отчёт учитывает только импульсные приборы учёта воды, подключённые к регистраторам импульсов. Для статистики по цифровым водосчётчикам предназначен отдельный отчёт №94.

Порядок работы:

  1. В панели ресурсов (слева) выберите «Экономика»
  2. В выпадающем списке отчётов выберите «№90 — Статистика опросов. Вода импульсная».
  3. В появившемся календаре укажите дату, за которую необходима статистика.
  4. Дождитесь формирования отчёта в центральной области экрана.
  5. Для выгрузки данных в файл Excel нажмите кнопку «Экспорт», расположенную рядом с выпадающим списком отчётов.

Состав отчёта:

Отчёт состоит из двух таблиц:

Первая таблица — общая статистика по всем импульсным водосчётчикам:

  • Корпус;
  • Количество опрошенных приборов;
  • Общее количество счётчиков;
  • Процент опроса;
  • Количество счётчиков, которые не были опрошены.

Вторая таблица — подробная информация по приборам, которые не были опрошены:

  • Имя абонента;
  • Номер прибора учёта;
  • Тип прибора учёта;
  • Номер регистратора импульсов;
  • Канал подключения;
  • IP-сокет.
Примечание: При выгрузке отчёта в файл Excel каждая таблица размещается на отдельном листе: первая таблица — на первом листе, вторая таблица — на втором листе.

Сформированный файл отчёта будет сохранён в папку «Загрузки» (или иную директорию, заданную в настройках вашего браузера).
