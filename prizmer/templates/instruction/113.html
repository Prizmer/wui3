Отчёт №113: Потребление за период. 3 тарифа

Назначение отчёта: формирование детального анализа потребления электроэнергии за выбранный период с отображением динамики по дням, показаний на начальную и конечную дату, а также расхода по каждому из трёх тарифов (T1, T2, T3).

Порядок работы:

  1. В панели ресурсов (слева) выберите «Электроэнергия»
  2. В дереве объектов раскройте нужный объект (ЖК, корпус).
  3. В выпадающем списке отчётов выберите «№113 — Потребление за период. 3 тарифа».
  4. В появившейся панели календарей укажите:
    • Начальную дату — дата начала периода;
    • Конечную дату — дата окончания периода.
  5. Дождитесь формирования отчёта в центральной области экрана.
  6. Для выгрузки данных в файл Excel нажмите кнопку «Экспорт», расположенную рядом с выпадающим списком отчётов.

Состав отчёта:

После формирования в отчёте отображаются:

  • График потребления — визуальное представление динамики потребления по дням выбранного периода;
  • Таблица данных, содержащая:
    • Показания приборов учёта на начальную дату;
    • Показания приборов учёта на конечную дату;
    • Расход (потребление) по каждому из трёх тарифов (T1, T2, T3).
Примечание: При выгрузке отчёта в файл Excel в таблицу автоматически добавляются поля с рассчитанной энергией — выполняется пересчёт показаний с учётом коэффициентов трансформации (КТТ, КТН). Для квартирных приборов учёта указанные коэффициенты, как правило, равны единице.
Важно: Если на выбранную начальную или конечную дату в базе данных отсутствуют показания по одному или нескольким приборам учёта, в соответствующих ячейках таблицы будет отображено значение Н/Д (или иное значение, предусмотренное индивидуальными настройками отчёта).

Сформированный файл отчёта будет сохранён в папку «Загрузки» (или иную директорию, заданную в настройках вашего браузера).
