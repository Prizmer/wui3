2.4 Панель администратора

Назначение: панель администратора (Django Admin) предоставляет полный доступ ко всем данным системы. Доступ к панели разрешён только для суперпользователей.

Вход в панель администратора

Для перехода к панели администратора нажмите на кнопку «Панель администратора», расположенную под деревом объектов, или перейдите по адресу /admin/.

Важно: Доступ к панели администратора имеют только пользователи с правами суперпользователя. Обычные пользователи при попытке входа получат ошибку доступа.

2.4.1 Com порты (ComportSettings)

Настройка COM-портов для опроса счётчиков через последовательный интерфейс.

↓

Рисунки 38-39. Настройка COM-портов

Поля для настройки:

  • Name — номер COM-порта (например, COM1, COM2);
  • Baudrate — скорость передачи данных (9600, 19200, 38400, 57600, 115200);
  • Data bits — количество бит данных (обычно 8);
  • Parity — чётность (0 — None, 1 — Odd, 2 — Even);
  • Stop bits — стоповые биты (1 или 2);
  • Write timeout — таймаут записи в секундах;
  • Read timeout — таймаут чтения в секундах;
  • Attempts — количество попыток опроса;
  • Delay between sending — задержка между отправками команд (мс);
  • Использовать CSD канал? — для GSM-модемов;
  • GSM phone number — номер телефона модема;
  • GSM init string — строка инициализации модема.

2.4.17 Счётчики (Meters)

Все приборы учёта системы.

⚠️ Критичный раздел: Удаление прибора из системы делает невозможным его восстановление.
↓

Рисунки 70-71. Счётчики

Поля для настройки:

  • Name — имя счётчика в системе;
  • Address — сетевой адрес;
  • Password — пароль;
  • Attr1 — номер стояка (для водосчётчиков);
  • Attr2 — дополнительный атрибут;
  • Attr3 — дополнительный атрибут;
  • Attr4 — номер этажа (для водосчётчиков);
  • Password type hex — использовать HEX для пароля;
  • Factory number manual — заводской номер (вручную);
  • Factory number readed — заводской номер (считанный);
  • Is factory numbers equal — совпадение номеров;
  • Dt install — дата установки;
  • Dt last read — дата последнего чтения;
  • Guid types meters — тип счётчика;
  • Guid meters — родительский счётчик (для импульсных — регистратор);
  • Time delay current — задержка текущего чтения.
Использование атрибутов для водосчётчиков:
  • Attr1 (номер стояка) — заполняется в формате «Стояк 1», «Стояк 2» или «Стояк 3». Используется в отчётах №60 и №67, где показания поквартирно выводятся в одну строку с группировкой по стоякам;
  • Attr4 (номер этажа) — заполняется номером этажа (например, «1», «2», «15»). Используется в отчёте №138 для отображения этажа рядом с показаниями.
Важно: Для корректной работы отчётов №60 и №67 необходимо, чтобы у всех водосчётчиков квартиры были заполнены атрибуты Attr1 (номер стояка). Если атрибут не заполнен, показания по такому счётчику не попадут в сгруппированный вывод.
