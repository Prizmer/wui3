Отчёт №41: Отчёт по форме 80020

Назначение отчёта: формирование отчёта по форме 80020 в соответствии с требованиями ПАО «Мосэнергосбыт». Сформированный файл соответствует установленным требованиям и отличается от данных, отображаемых в веб-интерфейсе системы (в веб-интерфейсе отображаются данные по юридическому лицу отправителя, ИНН, договору с Мосэнергосбытом).

Порядок работы:

  1. В панели ресурсов (слева) выберите «Электроэнергия»
  2. В дереве объектов раскройте узел «Группы 80020».
  3. Выберите конкретную группу счётчиков (называется номером договора или юридическим лицом, на которое заключён договор).
  4. В выпадающем списке отчётов выберите «№41 — Отчёт по форме 80020».
  5. В появившейся панели календарей укажите:
    • Начальную дату — дата начала периода;
    • Конечную дату — дата окончания периода.
  6. Дождитесь формирования отчёта в центральной области экрана.
  7. Для выгрузки данных нажмите кнопку «Экспорт», расположенную рядом с выпадающим списком отчётов.

Состав отчёта:

После формирования отчёт представлен в виде двух таблиц:

Первая таблица содержит данные по счётчикам, принадлежащим выбранной группе:

  • Список счётчиков;
  • Разница показаний по каждому прибору учёта;
  • Сумма получасовых профилей мощности;
  • Процент сбора получасовых профилей.

Вторая таблица позволяет оценить наличие данных по каждому прибору за каждый день выбранного периода:

  • Дата;
  • № ПУ T0 A+;
  • № ПУ T0 R+;
  • Количество получасовок за каждый день.

Цветовая индикация второй таблицы:

  • Зелёный цвет — считаны все 48 получасовых профилей мощности;
  • Жёлтый цвет — считано менее 48 получасовых профилей мощности;
  • Красный цвет — на данную дату нет данных о получасовых профилях мощности.
Важно: Перед формированием отчёта необходимо проверить:
  • Наличие получасовых значений в базе данных (100% опроса по каждому прибору, входящему в группу 80020);
  • Учётные данные (отправитель, ИНН, номер договора);
  • Сумма получасовых показаний должна примерно совпадать с разницей по показаниям счётчика между начальной и конечной датой.
Примечание: При необходимости «дочитать» недостающие данные из счётчиков электроэнергии можно при помощи программы «Сервер опроса» в ручном режиме.

После выбора необходимых параметров и первичного контроля учётных данных нажмите кнопку «Экспорт». Результатом экспорта будет архив типа 80020_номер_договора_даты.zip, содержащий XML-файлы, составленные в соответствии с отчётом по форме 80020.

Сформированный архив будет сохранён в папку «Загрузки» (или иную директорию, заданную в настройках вашего браузера).
