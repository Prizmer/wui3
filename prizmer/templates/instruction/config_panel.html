2.3 Панель конфигурирования

Назначение: панель конфигурирования предоставляет набор инструментов для управления приборами учёта, загрузки данных и обслуживания системы. Доступ к панели осуществляется через соответствующую кнопку в виде разводного ключа, расположенную под деревом объектов. Кнопки отображаются в нижней части экрана вне зависимости от выбранного ресурса.

Доступные разделы панели:

  1. Загрузка файла — загрузка произвольных файлов на сервер;
  2. Цифровые приборы — загрузка цифровых приборов учёта, а также данных для отчёта по форме 80020;
  3. Импульсные приборы — загрузка импульсных приборов учёта;
  4. Замена счётчиков — замена заводского номера, обмен приборами местами, смена типа прибора;
  5. Информация по объекту — экспорт данных о приборах в формате .xlsx по ресурсам;
  6. Балансные группы — загрузка балансных групп;
  7. Профили мощности — загрузка html-файлов с получасовыми профилями мощности, удаление накопленных данных;
  8. Удаление приборов — массовое удаление приборов из базы данных.

2.3.1 Загрузка файла

Для загрузки файла на сервер перейдите в соответствующий раздел, выберите файл (или перетащите его в область загрузки) и нажмите кнопку «Загрузить».

2.3.2 Внесение данных о приборах учёта — цифровых и импульсных

Данные разделы предназначены для загрузки информации о новых цифровых и импульсных приборах в систему. Образец файла в формате .xlsx для загрузки можно экспортировать в соответствующей вкладке.

Для загрузки подготовленного файла необходимо:

  1. Выбрать файл в соответствующей строке;
  2. Указать лист документа;
  3. Нажать кнопку «Загрузить … приборы из файла».
Примечание: После завершения процедуры на экране отобразится информация о количестве успешно загруженных счётчиков.

2.3.3 Замена счётчиков

Данный раздел предназначен для замены заводского номера прибора, обмена двух счётчиков местами в базе данных, а также для смены типа (ГВС/ХВС) водосчётчика Пульсар.

  • Замена заводского номера: введите старый и новый номера, затем нажмите кнопку «Заменить»;
  • Обмен счётчиков местами: введите номера двух счётчиков одного типа и нажмите кнопку «Заменить»;
  • Смена типа водосчётчика Пульсар: введите номер прибора в соответствующую ячейку и нажмите кнопку «Заменить».

2.3.4 Информация по объекту

В этом разделе можно экспортировать в формате .xlsx информацию о приборах учёта в системе, сгруппированную по ресурсам.

Для экспорта файла нажмите на интересующий вас ресурс.

2.3.5 Балансные группы

Данный раздел предоставляет возможность загрузить балансную группу в систему.

Для загрузки балансной группы необходимо выбрать файл и нажать кнопку «Загрузить». Экспорт образца файла для загрузки осуществляется с помощью соответствующей кнопки.

2.3.6 Профили мощности

Этот раздел предназначен для загрузки в систему html-файлов, содержащих получасовые профили мощности, а также для удаления профилей прибора учёта из базы данных на определённую дату.

  • Загрузка профилей: выберите директорию с файлами и нажмите кнопку «Загрузить»;
  • Удаление профилей: введите заводской номер прибора учёта, выберите дату и нажмите кнопку «Удалить».

2.3.7 Удаление приборов

В этом разделе можно удалить сразу несколько приборов из базы данных с помощью файла.

Порядок удаления:

  1. Подготовьте ведомость (можно использовать файл, экспортированный из раздела «Информация по объекту»);
  2. Выберите файл и укажите лист в документе;
  3. Нажмите кнопку «Удалить».
Важно: После завершения процедуры на экране отобразится информация об удалённых приборах. Операция удаления необратима — убедитесь в корректности выбранных данных перед выполнением.
